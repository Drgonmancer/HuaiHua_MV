# 槐花MV 使用手册

[返回项目首页](../README.md) · [贡献指南](../CONTRIBUTING.md) · [更新记录](../CHANGELOG.md)

这份手册从本地素材制作开始，再介绍模型配置、商品宣传片和漫剧流程。你可以先编辑、搭建、合成，按需要逐步接入 AI。

## 安装与启动

### 准备环境

| 工具 | 用途 | 要求 |
| --- | --- | --- |
| Python | 运行后端 | 3.10 或更高版本 |
| FFmpeg、FFprobe | 验证音视频、合成、导出 | 安装后加入 PATH；FFmpeg 需包含 H.264 / AAC 编码器和字幕滤镜 |
| 浏览器 | 打开工作台 | 建议在桌面浏览器使用完整画布 |
| Node.js | 修改、构建前端 | 普通使用不需要；开发见贡献指南 |

先检查命令是否可用：

```powershell
python --version
ffmpeg -version
ffprobe -version
```

FFmpeg 与 FFprobe 通常来自同一安装包。安装后重新打开终端；需要中文烧录字幕时，系统还应有可用的中文字体。

### Windows 安装

下载并解压项目，在包含 `README.md`、`backend/` 和 `frontend/` 的根目录打开终端：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend/requirements.txt
.\.venv\Scripts\python.exe -X utf8 backend/app.py --open
```

默认地址为 <http://127.0.0.1:5088/>。安装完成后，可双击 **启动槐花MV.bat**，脚本优先使用项目内的虚拟环境；原 **启动画布.bat** 也可启动。

保持服务窗口开启。按 `Ctrl+C` 或关闭窗口停止应用。再次点击启动脚本，会在检测到已有本项目服务时打开页面。

如果端口被占用，换一个端口运行：

```powershell
.\.venv\Scripts\python.exe -X utf8 backend/app.py --port 5089 --open
```

### macOS / Linux 的 Python 启动方式

以下提供命令行入口；完整平台兼容性尚未验证，Windows 启动脚本不适用于这些系统。

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r backend/requirements.txt
.venv/bin/python -X utf8 backend/app.py
```

手动打开 <http://127.0.0.1:5088/>，并确保 FFmpeg 与 FFprobe 都在 PATH 中。

### 确认启动成功

1. 页面顶部显示“槐花MV”。
2. 点击作品标题旁的 **创作项目 ↗**，打开创作工作室。
3. 在 **配置** 中看到文字、图片、视频、音频服务状态，以及 FFmpeg 状态。
4. 没有填写模型配置时，“未配置”是正常状态，本地编辑功能仍可使用。

首页会读取最近保存的画布。新安装没有历史数据时，需要自己创建作品；文档截图中的示例作品不代表仓库附带用户数据库。

实际应用与静态资源集中在 `backend/`；根目录的 `app.py`、`requirements.txt` 和 `start.ps1` 是原命令的兼容入口。`.env` 与 `data/` 仍放在项目根目录，无需因目录整理重新配置或迁移作品。

## 无需 API Key 完成第一个成片

准备一段或几段至少 5 秒的视频，以及一份可使用的音频。首次建议使用 MP4 视频和 WAV 音频；同一段素材可复用到多个镜头。

### 1. 创建作品与分镜

1. 打开工作室的 **作品** 页，填写名称，例如“春日茶饮宣传片”。
2. 创作类型选择 **商品宣传片**，点击 **创建并打开**。
3. 在 **创意 / 剧本** 填写：

   > 为一款茶饮制作 15 秒宣传片，用商品特写、通勤使用场景和品牌收尾三个镜头，突出清爽口感与便携。

4. 目标时长改为 **15 秒**，比例选 **16:9**。
5. 分镜来源选 **本地模板草稿（无需供应商）**，点击 **用模板搭建分镜节点**。

会得到三个可编辑镜头。模板提供结构与初始文案，不会生成图片、视频或配音。

### 2. 把本地媒体应用到镜头

1. 进入 **素材库**，上传到分类选择 **视频**，上传视频文件。
2. 切换为 **音频** 分类，上传一份音频。
3. 在 **应用到哪个镜头** 选择第一个镜头。
4. 找到视频素材卡片，点击 **应用到镜头**。
5. 对音频卡片也点击 **应用到镜头**。
6. 对其余镜头重复操作。

视频和音频都会成为画布中的素材节点。同一镜头有两种媒体时，会建立本地音画合成节点，并替换该镜头当前的输出关联。

### 3. 合成镜头，再导出

1. 在 **分镜** 点击 **运行当前分镜**，等待本地音画合成完成。
2. 进入 **时间线**，确认每个镜头显示 **视频已就绪**。
3. 裁切起点先用 `0`，终点设为 `5`；若视频更短，改为实际可用范围。
4. 编辑每个镜头的字幕。
5. 可选择背景音频作全片混音；没有需要时不选。
6. 选择 **720p** 和 **24 fps**，点击 **合成并导出成片**。
7. 工作台会切换到 **任务**。完成后预览视频，点击 **下载视频**。

成片按时间线顺序拼接，输出 MP4，包含音轨；填写的字幕会烧录到画面，并保留 MP4 字幕轨道。

如果只需要保留视频原声，先清空对应镜头的 **对白 / 旁白**，重新搭建分镜节点，再仅应用视频素材，便可在时间线直接导出。若镜头已经关联配音合成节点，需要完成合成或重新搭建无配音镜头，时间线才会选用有效结果。

## 模型服务配置

### 创建配置文件

从项目根目录复制配置示例。若已有 `.env`，直接编辑原文件，避免覆盖已保存配置。

```powershell
Copy-Item .env.example .env
```

在本机编辑 `.env`，只填写需要使用的服务。每类服务都需要 **Base URL、API Key、模型 ID** 三项：

| 服务 | 配置项 | 用途 |
| --- | --- | --- |
| 文字 | `TEXT_BASE_URL`、`TEXT_API_KEY`、`TEXT_MODEL` | AI 分镜、工作流搭图、提示词辅助 |
| 图片 | `IMAGE_BASE_URL`、`IMAGE_API_KEY`、`IMAGE_MODEL` | 文生图、带参考图片的图生图 |
| 视频 | `VIDEO_BASE_URL`、`VIDEO_API_KEY`、`VIDEO_MODEL`、`VIDEO_PROTOCOL` | 任务提交、状态查询、结果下载 |
| 配音 | `AUDIO_BASE_URL`、`AUDIO_API_KEY`、`AUDIO_MODEL` | 将台词转为语音 |

Base URL 要包含供应商要求的版本路径，如 `/v1` 或 `/api/v3`。不要重复追加具体接口路径；程序会接上 `/chat/completions`、`/images/generations` 等路径。

API Key 只填写到本机 `.env` 或进程环境。不要提交到 GitHub，不要放入浏览器代码、截图或 Issue。已有进程环境变量优先于 `.env` 中同名变量。

### 选择视频协议

| `VIDEO_PROTOCOL` | 程序使用的接口 | 当前适配边界 |
| --- | --- | --- |
| `seedance` | `/contents/generations/tasks` | Base URL 通常包含 `/api/v3`；有首帧与尾帧输入，当前菜单提供 5 / 10 秒，实际支持取决于供应商与模型 |
| `openai` | `/videos` 与任务结果接口 | 当前适配限定 4 / 8 / 12 秒、720p、16:9 或 9:16；不支持尾帧输入 |

这里的 `openai` 是协议适配名称，不是供应商可用性保证。请先确认你的服务提供这套接口，以及模型对参考图、时长和尺寸的要求。

文字、图片、音频适配使用 OpenAI 格式接口；支持这种格式不代表所有参数都被每个供应商接受。

### 模型目录、声音与并发

| 可选配置 | 作用 | 默认或说明 |
| --- | --- | --- |
| `TEXT_MODELS`、`IMAGE_MODELS`、`VIDEO_MODELS`、`AUDIO_MODELS` | 配置模型目录 | 逗号分隔；默认模型仍由对应 `*_MODEL` 指定。文字规划当前使用 `TEXT_MODEL` |
| `AUDIO_VOICES` | 声音 ID 目录 | 逗号分隔。留空时使用程序内置的 `alloy,echo,fable,onyx,nova,shimmer` 名称，需确认供应商实际支持 |
| `MAX_WORKERS` | 后台任务工作线程数 | 默认 `2` |
| `MAX_PENDING` | 后台同时接受的未结束任务上限 | 默认 `16` |
| `VIDEO_POLL_INTERVAL` | 视频供应商轮询间隔 | 默认 `3` 秒 |

同一个配音请求最多 4,000 字。角色的 `voice_id` 需要属于配置的声音目录；并不是上传音频后自动克隆声音。

### 生效与验证

1. 保存 `.env`，停止旧服务，再重新启动。
2. 在 **配置** 点击 **刷新状态**，检查需要的服务是否显示 **已配置**。
3. 用一个简单文本、单张图片或短镜头做小规模实际验证。
4. 验证会向供应商发请求，可能产生费用；先核对模型和参数。

“已配置”只确认配置项与基本 URL / 协议格式，不检查余额、权限或实际生成质量。没有配置的服务会明确返回错误，不自动切换到别的供应商。

## 商品宣传片案例

以“春日茶饮”为例，用三个 5 秒镜头串起一支 15 秒宣传片。

| 镜头 | 目标 | 画面与动作 | 旁白示例 |
| --- | --- | --- | --- |
| 商品亮相 | 让观众认出商品 | 清晨窗边，瓶身特写，柔和自然光，缓慢推进 | 把春天的清爽，带在身边 |
| 卖点演示 | 展示真实使用场景 | 通勤桌面，手持茶饮，突出便携与口感 | 忙碌之间，也能轻松喝一口 |
| 品牌收尾 | 留下品牌印象 | 瓶身与背景定格，预留文案区域 | 春日轻茶，开启清爽一天 |

### 设置商品与参考图

1. 创建 **商品宣传片** 作品，在 **创意 / 剧本** 明确商品、受众和核心卖点。
2. 在 **素材库** 以 **商品** 分类上传真实商品图片。
3. 在 **角色 / 场景** 的 **商品 / 出镜角色** 中填写商品名称、包装形状、颜色和应保留的标签。
4. 在参考图片中选择上传的商品图；补充场景描述与场景参考。
5. 使用模板或 AI 规划创建镜头。设置好后重新 **搭建分镜节点**，让引用进入节点图。

每个镜头的商品、角色和场景参考图片总计最多 6 张。参考图会进入生成任务；生成后仍需逐镜头核对包装、标志、文字和实际卖点，不把未确认的商品效果写成事实。

### 执行与交付

先运行一个镜头确认效果，再运行当前分镜。检查图片结果、视频运动、旁白和音画合成结果，在时间线裁切、改字幕并导出。

生成时长可能长于镜头的剪辑时长：视频节点会按当前适配目录调整为支持的时长，时间线再按你的目标长度裁切。导出分辨率只控制成片尺寸，不保证提升原素材的清晰度。

## 电影感国漫案例

例子：少女“阿槐”在雨后的古城找到一枚花种，与灵兽相遇，却发现花种会引来追踪者。

### 建立角色、场景与分集

1. 创建 **漫剧 / 分集故事**，默认画风为 **电影感国漫**。
2. 在 **创意 / 剧本** 填写故事设定、本集目标、比例和时长；首次建议从 15 秒、3 个镜头开始。
3. 在 **角色 / 场景** 添加“阿槐”和灵兽，分别填写外貌、服装、性格和参考图片。
4. 在角色 **配音 voice_id** 填写要使用的声音 ID。
5. 添加古城场景，记录地点、天气、光线和应保持的建筑特征。
6. 添加分集，例如“第一集：古城拾种”，填写梗概和剧本。

### 规划镜头与对白

| 镜头 | 情节 | 示例对白 |
| --- | --- | --- |
| 开场建立 | 阿槐在雨后的石阶发现发光花种 | 这枚种子……为什么在发光？ |
| 冲突发展 | 灵兽挡在身前，远处脚步声逼近 | 快走，他们已经找到这里了 |
| 结尾悬念 | 花种浮现山海图案，指向下一集 | 原来，你一直在等我 |

1. 选择 **本地模板 / 手动分镜**，或配置文字服务后选择 **AI 规划**。
2. 逐镜头编辑画面、图片提示词、视频动作、对白、时长与所属分集。
3. 为镜头选择 **出镜角色 / 商品** 和场景，确认对应参考图片。
4. 需要单集节点图时，使用 **分集筛选**，再搭建节点。
5. 运行后检查同一角色在不同镜头的服装、脸型、比例和声音是否符合设定。

当前每个镜头使用一段对白和一个配音节点，优先采用出镜角色中首个非空声音 ID；它不是多角色自动对口型系统。对话较复杂时，把台词拆成独立镜头或自行整理音频再应用到镜头。

### 单集或完整作品导出

在 **时间线 → 导出分集** 中选择一集，或选择 **全部镜头 / 完整作品**。确认镜头顺序、字幕和配音，选择需要的背景音频后导出。

一条时间线可以组织多个分集，但长篇剧情一致性、角色稳定性和声音表演仍需要逐集审阅。

## 画布与工作室怎么配合

| 操作 | 方法 |
| --- | --- |
| 打开工作室 | 点击顶部作品类型旁的 `↗` 按钮 |
| 添加节点 | 双击画布空白处，选择节点类型 |
| 连接引用 | 从上游输出端口拖到下游输入端口，类型和容量会校验 |
| 批量选择 | 按住 `Shift` 框选；`Ctrl` / `Meta` 配合多选 |
| 复制节点 | 选中后按 `Ctrl+D` / `Cmd+D` |
| 删除节点 | 选中后按 `Delete` / `Backspace`；输入框内使用正常文本编辑 |
| 查看全图 | 点击左下角 Fit View；分镜页也有 **查看分镜画布** |
| 返回镜头编辑 | 重新打开工作室的 **分镜** 页 |

工作室保存“剧本和镜头应该是什么”，画布保存“如何引用素材并执行”。重新搭建会追加节点，保留已有图；编辑后需要重建的镜头会解除旧节点关联。

修改镜头提示词、对白、角色、场景、剧本或画风后，请重新搭建对应节点。旧图仍可查看，但不会作为修改后镜头的有效媒体。仅调整顺序、裁切或字幕时，可以保留已有视频。

素材分类中，**商品、角色、场景、参考** 只接受图片；视频和音频需放入对应分类。图片单文件上限 10 MB，音视频上限 100 MB，服务会检查实际格式。首次推荐 PNG / JPEG 图片、MP4 视频和 WAV 音频。

## 任务、失败与恢复

| 状态 | 含义 | 下一步 |
| --- | --- | --- |
| 排队中 | 已记录任务，等待执行 | 等待或取消 |
| 处理中 | 供应商生成或本地媒体处理正在进行 | 查看任务，避免重复提交 |
| 已完成 | 有可查看的产物 | 检查质量后继续下游或下载 |
| 失败 | 提交、生成、下载或处理未成功 | 读错误信息，修复配置或素材后决定重试 |
| 已取消 | 本地处理停止 | 确认供应商端状态，再决定重新运行 |

重复提交同一个请求 ID 会复用记录。页面刷新会通过已有任务 ID 或请求回执恢复；缺少确认信息时不会自动补发请求。应用重启后，未完成任务会标记为中断，需要手动检查。

**取消不等于供应商退款**，已经接受的任务可能继续生成。**重试是一个新请求**，可能再次收费。历史失败任务不应覆盖镜头较新的结果；编辑过的内容请从当前镜头重新搭建和运行。

当前不提供供应商间自动回退，也不提供云端账户或团队任务队列。

## 保存与备份

保存状态中的“在线”表示浏览器已连接本地服务并完成保存，不代表上传到云端。

- **本地草稿**：浏览器保留当前编辑，尚未确认写入数据库。
- **同步中**：正在保存到本地服务。
- **在线 · 已同步**：当前内容已确认保存。
- **离线**：服务暂不可达，浏览器保留草稿，恢复后尝试同步。

切换作品前会保存；关闭页面前等待 **已同步**。草稿冲突时，比较后选择 **保留本地草稿** 或 **用服务器版本**。

| 位置 | 内容 |
| --- | --- |
| `data/canvas.db` | 作品、节点、生产资料、素材记录和任务 |
| `data/studio-media/` | 素材、生成结果、导出文件 |
| `data/uploads/` | 原图片节点上传的兼容目录 |
| 浏览器 localStorage | 当前浏览器的草稿 |
| `.env` | 本机模型配置与密钥 |

备份时先停止服务，复制完整 `data/` 目录。数据库与素材必须一起保存；只备份 `.db` 会缺少媒体文件。迁移到另一台机器后，把 `data/` 放回项目根目录，并在新机器单独配置环境与供应商。

浏览器草稿按本地地址保存；更换端口或浏览器不会自动带走未同步草稿。`.env` 不属于分享素材，不要放入公开备份。

## 常见问题

| 问题 | 建议检查 |
| --- | --- |
| 双击启动失败 | 检查 Python、`backend/requirements.txt` 依赖和启动窗口错误；虚拟环境必须在项目 `.venv` 中 |
| 端口被占用 | 使用 `--port 5089`；保留原地址，先确认草稿已经同步 |
| 模型菜单为空 / 服务未配置 | 检查对应 Base URL、API Key、模型 ID；改 `.env` 后停止旧进程再启动 |
| 已配置但生成失败 | 检查供应商余额、模型权限、协议、参数与任务记录；“已配置”不是实际生成测试 |
| 找不到 FFmpeg | 检查 `ffmpeg -version` 和 `ffprobe -version`；加入 PATH 后重启终端与应用 |
| 上传失败 | 检查分类、大小和格式；视频上传到“视频”，音频上传到“音频”；不要仅改扩展名 |
| 镜头没有可用视频 | 运行依赖节点，或从素材库应用视频；有配音合成节点时先完成音画合成 |
| 改了剧本却无法导出旧镜头 | 这是内容失效保护；重新搭建并运行镜头，或重新应用本地媒体 |
| 视频时长被调整 | 模型目录限制生成时长；在时间线裁切到目标长度 |
| 中文字幕缺字 | 检查本机中文字体与 FFmpeg 字幕滤镜，建议先导出一段短测试片 |
| 重启后任务显示失败 | 查看错误与供应商端任务，确认是否已有产物，再决定手动重试 |
| 修改前端后页面没变化 | 在 `frontend/` 运行 `npm run build`，检查 `backend/static/canvas/` 产物，再刷新页面 |

需要反馈时，在本仓库 Issues 中附上操作步骤、系统与工具版本、脱敏错误信息。不要提供密钥、`.env` 或个人素材。参见 [贡献指南](../CONTRIBUTING.md#反馈-bug)。
